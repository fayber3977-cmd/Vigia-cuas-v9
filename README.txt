VIGÍA C-UAS V9
PWA experimental de observación y registro.

PUBLICACIÓN
1. Crear repositorio público llamado Vigia-cuas-v9.
2. Subir index.html, styles.css, app.js, manifest.webmanifest, sw.js y README.txt.
3. Subir la carpeta icons con icon-192.png e icon-512.png.
4. GitHub Settings > Pages > Deploy from a branch > main > /(root) > Save.

IMPORTANTE
- Cámara y GPS requieren permisos y conexión segura HTTPS.
- El mapa y sus mosaicos requieren internet.
- El análisis de movimiento compara cambios entre fotogramas; puede producir falsos avisos.
- No identifica drones, aeronaves ni amenazas. No es radar ni detector RF.
- Los datos se guardan en el almacenamiento local del navegador. Exporta JSON regularmente.
- Importar JSON reemplaza los registros actuales.
